# Лабораторная работа №2 — потоки, процессы и асинхронность

Проект сравнивает `threading`, `multiprocessing` и `asyncio` на двух задачах:

1. вычисление суммы чисел от 1 до `10_000_000_000_000`;
2. параллельная загрузка веб-страниц с сохранением заголовков в таблицу `tasks` базы TimeFlow из ЛР1.

## Почему в задаче 1 используется формула

Последовательный перебор десяти триллионов чисел занял бы слишком много времени. Функция `calculate_sum(start, end)` использует формулу арифметической прогрессии, а общий диапазон всё равно делится на четыре непересекающиеся части. Поэтому программа выполняет требование и получает точный результат:

```text
50000000000005000000000000
```

Так как каждая часть вычисляется за постоянное время, результаты замера показывают главным образом накладные расходы на создание потоков, процессов и цикла событий. Это нужно честно указать в выводе.

## Установка на macOS

Из папки `Lr2`:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
cp .env.example .env
```

В `.env` укажите тот же пароль PostgreSQL, что и в ЛР1. `PARSER_USER_ID=1` означает, что результаты парсинга будут добавлены как задачи пользователя с id 1.

## Запуск задачи 1

```bash
python -m task1.threading_sum
python -m task1.multiprocessing_sum
python -m task1.async_sum
python -m task1.benchmark
```

Последняя команда запускает все три варианта и сохраняет таблицу в `results/task1_times.csv`.

## Запуск задачи 2

PostgreSQL и база `timeflow` должны быть запущены, а миграция ЛР1 уже применена.

```bash
python -m task2.threading_parser
python -m task2.multiprocessing_parser
python -m task2.async_parser
```

После каждого запуска откройте Swagger ЛР1 и выполните `GET /tasks`: заголовки страниц появятся как новые задачи со статусом `planned` и приоритетом `low`. Поле `description` содержит URL и название подхода.

Повторный запуск создаёт новые записи — это удобно для демонстрации каждого подхода отдельно.

## Тесты

Тесты не обращаются к интернету и PostgreSQL:

```bash
pytest -q
```

## Функции из задания

- Во всех файлах задачи 1 используется `calculate_sum()` из `task1/common.py`.
- В каждом файле задачи 2 определена `parse_and_save()`.
- Список URL делится на части в вариантах с потоками и процессами.
- `asyncio` запускает отдельную корутину на каждый URL через `asyncio.gather()`.
